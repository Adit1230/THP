This python program uses opencv library to create a depth map from a stereo image pair.
The dataset is stored in the data folder. In this folder there are many folders with stereo image pairs.
Depth map has been calculated for each image pair and stored in the same folder
We can see that the model is able to more accurately identify depth of larger objects but struggles with smaller objects.
The model performs better on outdoor images with better lighting.

Requirements:

OpenCV
